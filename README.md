# Utkarsh Yadav - Portfolio Website

A sophisticated, terminal-inspired portfolio website showcasing ML/Gen AI engineering expertise.

## 🚀 Features

- **Terminal Aesthetics**: Code editor-inspired design with monospace fonts and syntax highlighting
- **Interactive 3D Elements**: Three.js powered 3D brain and geometric shapes
- **Advanced Animations**: Typewriter effects, matrix rain, cursor trails, and glitch effects
- **Neural Network Background**: Animated canvas-based neural network visualization
- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **Accessibility**: Keyboard navigation and screen reader friendly

## 🛠️ Tech Stack

- **Framework**: React 18 with Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **3D Graphics**: Three.js, React Three Fiber
- **Charts**: Chart.js
- **Icons**: Lucide React

## 📦 Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📧 Contact Form Setup

The contact form uses **EmailJS** (React-only, no backend needed).

See [EMAILJS_SETUP.md](./EMAILJS_SETUP.md) for detailed setup instructions.

**Quick setup:**
1. Create EmailJS account at [emailjs.com](https://www.emailjs.com/)
2. Add Gmail service with your credentials
3. Create email template
4. Update IDs in `src/components/Contact.jsx`
